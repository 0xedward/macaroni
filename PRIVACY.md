# Privacy Policy for Macaroni

**Last Updated:** January 2026

## Overview

Macaroni is a browser extension that encodes selected text into various formats (Base64, URL encoding, HTML entities, and JSON escaping) and copies the result to your clipboard.

## Data Collection

**Macaroni does not collect, store, or transmit any user data.**

Specifically:
- **No personal information** is collected
- **No browsing history** is tracked
- **No analytics or telemetry** is sent
- **No cookies** are used
- **No data** is sent to external servers

## How the Extension Works

1. When you select text and use the context menu, the extension reads only the selected text
2. The text is encoded locally in your browser
3. The encoded result is copied to your clipboard
4. No data is stored or transmitted anywhere

## Permissions

The extension requests the following permissions:
- **contextMenus**: To add encoding options to the right-click menu
- **notifications**: To notify you when text has been copied
- **activeTab**: To access selected text only when you invoke the extension
- **scripting**: To copy text to your clipboard
- **clipboardWrite**: To write the encoded text to your clipboard

These permissions are the minimum required for the extension to function.

## Third-Party Services

Macaroni does not use any third-party services, APIs, or analytics platforms.

## Changes to This Policy

Any changes to this privacy policy will be posted in this document and the extension will be updated accordingly.
